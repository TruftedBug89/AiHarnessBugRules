# Privacy Rules

## 1. Never inspect or access conversations with other AIs, especially local AI

- **NEVER check, view, read, search, parse, or log conversations, chat logs, history, or session files from other AI tools, assistants, or local AI applications** (e.g., LM Studio, Ollama, Jan, Text-Gen-WebUI, ChatGPT transcripts, Claude logs, etc.).
- User conversations and interaction histories with AI models are strictly private and confidential.
- Do not inspect conversation folders or history files (e.g., `conversations`, `chats`, `history`, `session_cache`, `.internal`, `.conversation.json`) even when diagnosing runtime configurations or parameters.
- If model configuration or presets need to be determined, ask the user directly or use explicit CLI flags / settings definitions rather than reading past chat histories.
